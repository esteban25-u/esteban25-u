# Portafolio personal

Sitio estático personal creado con HTML y CSS, listo para publicar con GitHub Pages. No requiere instalar dependencias.

## Personalízalo

Antes de publicarlo, abre `index.html` y reemplaza los datos de ejemplo:

- `Tu Nombre`, tu ciudad, carrera o área.
- `tu-usuario` en los enlaces de GitHub y LinkedIn.
- `tu-correo@ejemplo.com` por tu correo.
- La lista de tecnologías que conoces.

También puedes cambiar las iniciales `TN` del encabezado y pie de página. La sección de proyectos enlaza directamente a tus repositorios de GitHub; no incluye proyectos de ejemplo.

## Publicar con GitHub Pages

1. Crea un repositorio en GitHub. Para un sitio personal, puedes llamarlo `tu-usuario.github.io`; también puedes usar cualquier otro nombre.
2. Sube `index.html`, `styles.css` y `README.md` a la rama principal (`main`).
3. En el repositorio, ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/ (root)`, y pulsa **Save**.
6. Cuando termine la publicación, GitHub mostrará la URL del sitio en esa misma sección.

Los cambios posteriores se publican automáticamente al subirlos a la rama seleccionada.
